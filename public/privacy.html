Privacy & Data Security

Last updated 25 November 2026

This page explains what information we collect, why, and how we look after it. It covers this website, our hosting, and contacting us.

This website

This site has no analytics, advertising or tracking cookies. It’s a static site hosted on Vercel, and a few other services see your requests when you visit:

  • Vercel serves the site and keeps standard request logs, such as your IP address and browser details. See Vercel’s privacy policy.
  • Google Fonts provides the typeface, so Google receives your IP address when the font loads.
  • GitHub provides member avatars and the files shown on the projects page, so GitHub receives those requests.

When you contact us

If you email us or message us on Discord, we keep the conversation so we can reply and, if you become a partner, so we have a record of what we agreed.

Partners

If you’re a partner, we hold what we need to run your service:

  • your contact details;
  • the files, data and configuration you host with us;
  • server logs, which can include IP addresses, timestamps and request details.

We use logs for security and troubleshooting, and keep them only as long as we need them for that.

What we don’t do

We don’t sell personal information, and we don’t use it for advertising. We only share it when the law requires us to, or with services we rely on to operate, such as Vercel and Discord.

Where data is stored

Our servers are in Sydney, Australia. Services we use, like Vercel, GitHub, Google and Discord, may store data in other countries under their own policies.

Data security

  • We run and administer our own servers. Access is limited to AxisNet.work members.
  • We apply security updates to our servers and software.
  • This website is only served over HTTPS.
  • We don’t look through partner data unless we need to for troubleshooting, security, or an abuse report.

No system is perfectly secure. If a breach affects your information, we’ll tell you as soon as we can, explain what happened, and say what we’re doing about it.

Keeping and deleting data

When a partnership ends, we give you a chance to take a copy of your data, then delete it from our servers. You can ask us what information we hold about you, ask us to correct it, or ask us to delete it, by emailing support@axisnet.work.

Changes

If we change how we handle information, we’ll update this page and the date at the top. We’ll let partners know directly about significant changes.
